# Промпт 0 — Забери своего персонажа (занятие 1)

**Когда:** самый первый шаг, до всего остального. Тебе нужна папка твоего персонажа.
**Что делает:** Claude Code сам скачивает папку выбранного персонажа из репозитория занятия
прямо к тебе в подпапку `Persona/` — тебе не нужно ничего качать вручную.
**Как использовать:** создай пустую папку для проекта, открой её в VS Code (`File → Open Folder…`),
запусти Claude Code и отправь промпт ниже — подставив ссылку, которую дал преподаватель,
и имя своего персонажа.

> Ссылку на репозиторий занятия преподаватель даёт в начале урока. Список персонажей
> (и их короткие имена-папки) — в README этого репозитория.

```text
Склонируй этот публичный репозиторий во временную папку. Создай в моей текущей
рабочей папке подпапку Persona/ (если её ещё нет) и перенеси туда содержимое
ТОЛЬКО одной подпапки репозитория — моего персонажа. Временную папку после
переноса удали, весь остальной репозиторий мне не нужен.

Репозиторий: <ВСТАВЬ ССЫЛКУ, которую дал преподаватель>
Персонаж: <короткое имя папки, например scrooge-mcduck — список в README репозитория>

У меня в рабочей папке должна получиться такая структура:

Persona/
  про-меня.md
  проекты.md
  факты.md
  images/
    ...несколько картинок...
    CREDITS.md

Когда закончишь — покажи дерево того, что оказалось в моей папке.
```

Когда файлы окажутся на месте — переходи к промпту [`01-about-page.md`](01-about-page.md)
и собери свою страницу.

> Ведёшь себя, а не персонажа? Тогда качать нечего — просто создай папку `Persona/`,
> а в ней три файла `про-меня.md`, `проекты.md`, `факты.md` и напиши в них про себя.
> Дальше всё то же самое.
