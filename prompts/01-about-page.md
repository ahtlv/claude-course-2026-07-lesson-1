# Промпт 1 — About-страница (занятие 1)

**Когда:** первый практический шаг. У тебя есть папка с описанием персонажа (или твоя собственная).
**Что делает:** Claude Code читает описание и собирает красивую одностраничную визитку, потом открывает её в браузере.
**Как использовать:** открой папку в VS Code, запусти Claude Code, скопируй текст из блока ниже и отправь (можно надиктовать голосом через Handy).

> Этот промпт — не священный текст. Меняй под себя: хочешь другой стиль, тёмную тему, больше разделов — прямо так и допиши в конце.

```text
Ты работаешь в этой папке — здесь лежат файлы с описанием персонажа
(про-меня.md, проекты.md, факты.md).

Задача: собрать одну красивую HTML-страницу «About / визитка» на основе этих файлов.

Сначала прочитай все файлы в папке — это твой контекст о персонаже.
Загляни и в подпапку images/ — там картинки персонажа и файл CREDITS.md
с их авторами и лицензиями.

Потом сделай страницу index.html:
- один файл, все стили внутри (CSS в <style>), без внешних библиотек;
- разделы: имя и краткое интро сверху, «обо мне», «чем занимаюсь», интересные факты;
- приятный современный дизайн: аккуратная типографика, воздух, один акцентный цвет;
- адаптивно под телефон;
- понятный заголовок вкладки браузера (<title>);
- на русском языке, тон — как в исходных файлах.

Картинки из подпапки images/ (если она есть):
- одно из изображений поставь большим в шапку — какое именно, не важно, выбери любое подходящее;
- остальные разложи по смыслу — в раздел «чем занимаюсь» и как акценты;
- одну тёплую/атмосферную дай в финал рядом с цитатой;
- обрезай по месту (object-fit: cover), мелкие картинки не растягивай;
- если текст лежит поверх фото (шапка, финал) — затемни фон под ним (тёмная
  накладка/градиент), чтобы текст читался на любой картинке;
- внизу страницы добавь мелким шрифтом строку с источниками картинок по данным
  из images/CREDITS.md (автор + лицензия) — этого требуют лицензии.
Если папки images/ нет — просто собери страницу без картинок.

Когда закончишь — открой index.html в браузере (на Mac — командой `open index.html`), чтобы я сразу увидел результат.
```

**После того как страница откроется** — попроси Claude что-нибудь поменять своими словами: «сделай фон теплее», «добавь раздел с цитатой», «увеличь заголовок». Это и есть работа с агентом: ты говоришь — он делает.

### ⭐ Не нравится картинка? Поставь свою (бонус для «вау»)

Картинки для персонажей подобраны автоматически — дёшево и быстро, свободные лицензии,
минимум ручной курации, — поэтому под конкретно твою страницу они могут подойти не
идеально. Это нормально: так выглядит результат дешёвой автоматизации, и сейчас у тебя
есть шанс её поправить. Хочешь усилить эффект — сходи в интернет, найди картинку получше
(своё фото, кадр в духе персонажа) и положи её к себе в папку — загляни, где уже лежат
остальные картинки персонажа, и пристрой свою рядом. Потом попроси агента: «сделай вот
эту картинку главной в шапке». Страница сразу станет по-настоящему твоей — а ты попутно
научишься подсовывать агенту свои файлы.
